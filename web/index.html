Veo 3.1 Prompt Format

Google's Veo 3.1 uses a structured four-section prompt format

[Setting]

Describe the environment, location, lighting, and atmosphere

[Action]

Define what happens, movements, events, and dynamics

[Camera & Style]

Specify camera movements, angles, framing, and visual style

[Output]

Technical specifications: resolution, frame rate, color grading

LtX Pro Prompt Format

Lightricks' LtX Pro uses a motion-focused four-section structure

[Description]

Describe the scene, subject, and visual environment

[Motion]

Define movement, dynamics, and action in the scene

[Framing]

Specify shot type, camera angle, and composition

[Cinematic Style]

Visual style, color grading, lighting, and technical specs

Production Tools

Node.js command-line tools for prompt management and production workflows

🔄 Generate Prompts

node tools/generate_prompts.js

Generates individual JSON files for Veo 3.1 and LtX Pro from the prompt library

  • Creates prompts/veo3_1/*.json
  • Creates prompts/ltx/*.json
  • Automatic format conversion
  • Index file generation

📝 Normalize Prompts

node tools/normalize_prompts.js [file.txt]

Converts raw text prompts into structured Veo 3.1 format

  • Interactive CLI mode
  • File batch processing
  • Auto-section detection
  • JSON output

🎬 Scene to Prompt

node tools/scene_to_prompt.js scene.md

Converts scene descriptions to Veo 3.1 and LtX prompts

  • Markdown parser
  • Camera term integration
  • Dual format output
  • Enhanced cinematography

📄 Export Prompt Sheet

Generates HTML and Markdown reference sheets

  • Copy-to-clipboard buttons

  • Genre organization

📊 Build Shotlist
